# `analysis/` — statistical stylometry of the Greek corpus

A self-contained research toolkit that reads the Greek TEI in `sources/` and asks
authorship questions about it. It is **independent of the reader pipeline**: it
writes nothing into `build/`, `app/`, or `manifests/`, and no site build depends
on it.

```
greekstyle/corpus.py     TEI -> normalised, Bekker-anchored token streams
greekstyle/works.py      the work registry (file, editor, authorship status)
greekstyle/features.py   function-word vocabularies; editor-sensitive features
greekstyle/stylo.py      Burrows's Delta, PCA, permutation tests, bootstrap
studies/                 the four studies
results/                 JSON output (regenerated by run_all.py)
```

## Running

Needs Python 3.11 and numpy; nothing else.

```bash
cd analysis
python3 -m pip install numpy          # only dependency
python3 run_all.py                    # all studies, ~1 minute
python3 -m studies.common_books       # or one at a time
```

## What it does

Splits each work into fixed-size chunks, counts 161 function words (particles,
connectives, prepositions, negatives, article, pronouns — 53% of all tokens),
z-scores them and measures Burrows's Delta. Function words are used rather than
all frequent words because this corpus ranges from zoology to ethics, and
content words would cluster the works by subject matter instead of by hand.

Corpus as loaded: **830,726 tokens, 48,244 types, 39 works.**

## Reading the results

`FINDINGS.md` has the results and the caveats; `report.html` is the same
material as a self-contained page with the figures drawn (published at
https://claude.ai/code/artifact/0480cf4b-78ed-4395-90da-fca27a9f9828). Two things are worth knowing
before trusting any number in it:

- **Genre is a real confounder** and is not fully removed. The most formal works
  (Topics, both Analytics, Physics) look "unlike Aristotle" on the corpus-wide
  test purely because logical prose uses εἰ, ὅτι, τι at different rates.
- **Length is a real confounder** in the book-level study, and is corrected for
  explicitly: shorter samples drift from any centroid for statistical reasons
  alone (r = −0.49 between log length and raw Delta).

Both are reported in the output rather than smoothed away.

## Known limits of the data

- Categories, De Interpretatione and the Isagoge have no Greek TEI in `sources/`
  — their Greek comes from a Diogenes/TLG export that needs the local TLG disc.
  The Isagoge in particular would have made an excellent control, being
  Porphyry's and not Aristotle's at all.
- Magna Moralia is not in the corpus, which is a real loss for the Ethics
  question: it is the third ethical treatise and Kenny's argument uses it.
- There is **no out-of-corpus author** to calibrate against (Theophrastus would
  be ideal). Network access from this environment is limited to the session's
  own repository, so nothing external could be fetched. The pseudo-Aristotelian
  works are the only "different author" signal available, and they are a
  ragbag of different authors rather than one control.
