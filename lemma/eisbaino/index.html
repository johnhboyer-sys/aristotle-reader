Dictionary (LSJ)

εἰσβαίνω, A. go on board a ship, mostly abs., embark, Od. 9.103, Th. 7.13, etc. ; ἐς [πεντηκόντερον] Hdt. 3.41 : c. acc., σκάφος E. Tr. 686. 2. generally, enter, πρὸς κόρης νυμφεῖον εἰ. S. Ant. 1205 ; δόμους E. Med. 380 ; εἰ. κακά come into miseries, S. OC 997 ; ἄτης ἄβυσσον πέλαγος A. Supp. 470 ; reversely, ἐμοὶ γὰρ οἶκτος.. εἰσέβη S. Tr. 298 ; κἀμὲ γὰρ τὸ δυσχερὲς τοῦτʼ εἰσβέβηκεν E. Hyps.Fr. 5(3).20. 3. come in, be imported, εἰσέβαινον ἰσχάδες Alex. 117. 4. project into, PTeb. 86.24 (ii B.C.), etc. II. causal in aor. 1, make to go into, put into, ἐς δʼ ἑκατόμβην βῆσε θεῷ (sc. ἐς νῆα) Il. 1.310, cf. E. Alc. 1055 (lyr.), Ba. 466 ; ληΐδα A.R. 2.167.
