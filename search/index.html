Type Greek in Greek letters or (texnh = τέχνη). * matches any run of characters; ? matches exactly one. What is this? Use either inside or at the end of a word, in Greek or English. At the start, * is read as the Beta Code capital marker and ignored — there is no suffix wildcard.
